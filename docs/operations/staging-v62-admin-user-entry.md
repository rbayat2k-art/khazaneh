## ۳. رفتار و رابطه‌ها

نشست جدا با توکن تازه و اعتبار حداکثر۳۰دقیقه، متصل به همان نشست مدیر؛ در هر درخواست و داخل صف دوباره ADMIN اصلیِ فعال/والد معتبر/مقصد فعال بررسی می‌شوند. مجوز، شرکت، سقف، ارجاع و خودتأییدی از کاربر مقصد می‌آیند. هدف مدیر اصلی یا خود مدیر قابل انتخاب نیست؛ غیرفعال مجاز نیست. دلیل ورود الزامی است. پایان فقط با اعتبار والد انجام می‌شود و child هیچ توکن ADMIN دریافت نمی‌کند. تغییر رمز خود/۲مرحله‌ای/لغو نشست‌های واقعی مقصد و تغییر vault اتصال در نمایندگی رد می‌شوند؛ مسیرهای دارای حروف بزرگ یا اسلش پایانی نیز پوشش دارند. تنظیمات معمولی کارتابل قابل ذخیره است.

مدیر اصلی در localStorage، نشست نمایندگی در sessionStorage همان تب؛ ورود/بازگشت reload کامل دارد تا فرم/modal/state/cursor قبلی منتقل نشوند. نوار ثابت نام کاربر، مدیر و بازگشت را نشان می‌دهد؛ تب دیگر مدیر می‌ماند. logout از پرتال نمایندگی همان بازگشت است. اعلان داخل پرتال متعلق به مقصد است؛ اعلان ویندوز در نمایندگی منتشر یا مصرف نمی‌شود. مبلغ و قواعد مالی تغییر نکردند. در همان commit، metadata دو هویت و شناسه ورود روی رویداد جدید/پرداخت/یادداشت/رکورد/صف استعلام می‌ماند؛ security event فقط مسیر و شناسه منابع را ثبت می‌کند. نمایش گردش و گزارش جامع، مدیر واقعی را نیز نشان می‌دهند؛ سابقهٔ قدیمی عوض نمی‌شود.
