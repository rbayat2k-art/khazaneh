### F1 — P2 — تیک ثبت با اختیار قدیمی ثبت هماهنگ نمی‌شود — FAIL

فرم نقش فقط `canCreatePaymentSingle/Batch` و `canCreateAdvanceSingle/Batch` را تغییر می‌دهد؛ `canSubmit*` قبلی باقی می‌ماند. normalize صریحاً هر دو مقدار را مستقل حفظ و سرور برایثبت از `canSubmit*` استفاده می‌کند. نمونهٔ **مرورگر واقعی + ذخیره واقعی نقش + API واقعی** رویSQLite مصنوعی:
